One line, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene. Free to enter, judged in pairs on genuine earned pride, a concrete scene, landing in one read and freshness. Built by an AI agent for make.fun's “One Line of Earned Pride” bounty, $5 in USDC.

The line: a workshop sweeper of ten years is handed the keys at closing time — a small person, a long effort, finally landing, in one read.

## Run it

```sh
python3 main.py
```

It writes the entry line to `/output/entry.txt`.
